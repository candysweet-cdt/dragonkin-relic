## 0. 五分钟快验（先跑这 8 条，挂了就不用往下）

- [ ] **1 创造栏**：出现「龙裔遗骸」页，21 格（17 物品 + 7 方块里有 4 张蛋在最末），图标无紫黑、无重影
- [ ] **2 召唤**：4 张蛋各放一只，全部正常出生、朝向正确、不卡地
- [ ] **3 动作**：站着看 5 秒，四只都有 idle 动作（龙蛇悬空浮动 + 尾巴摆；小怪身体起伏）
- [ ] **4 受击**：打龙蛇一下 → **红闪一下，动作不弹、浮空不断**（这是刚修的"受击动作被初始化"）
- [ ] **5 掉落**：打死龙蛇（生存击杀）→ 掉**龙鳞 6–10**、龙牙 2–4、龙心、龙蛋；再打几只小怪看有没有掉落
- [ ] **6 内讧**：**龙蛇 + 2 幼龙 + 1 龙卫 + 1 祭司**混着放，站旁边 15 秒 → 互不伤害、也互不锁定
      （重灾区是「BOSS 的震地/召唤误伤幼龙」；若看到互相挥击，日志里应有 `[fycq-guard] drop ally target …`，没有就是没生效）
- [ ] **7 创造不被追**：保持创造站在它们面前 5 秒 → 日志出 `[fycq-guard] drop target …`，怪物只盯着不追不打
- [ ] **8 脱战**：飞出 30 格外/躲墙后 10 秒再回来 → 它们已脱战，不隔墙一路追

## 1. 龙蛇（BOSS）· 外观与基础

- [ ] 血条：屏幕顶部出现 BOSS 血条，名字「龙蛇」（原版 `minecraft:boss` HUD）
- [ ] 碰撞：贴身走一圈，2.2×3.4 的框与身体大致吻合，翅膀大出的部分不挡路
- [ ] 死亡：血空后侧倒 + 下沉，尸体不残留
- [ ] 音效：低吼（约 8 秒一次）、受伤、死亡各有声（末影龙音色、降调）
- [ ] **翅膀边缘**：飞/悬空时盯翅膀边缘 → 不应有 1 像素长直线，也**不应有悬浮的矩形方框**（本轮把加厚膜的 1px 侧面清成透明）

- [ ] **召唤**：约每 22 秒召唤 2 只幼龙（幼龙从身边一圈出现）
- [ ] **阶段 2（≤66%）**：血条名变「龙蛇·血怒」；移速/伤害上升；震地更频繁；**火球变成龙息火球**（落地留伤害区）；会**冲锋**

- [ ] **召唤上限**：**每只龙蛇最多同时保有 6 只自己召的幼龙**、每只祭司最多 2 只；蛋召/野生的幼龙不计入也不受限
      日志 `[fycq-phase] boss summon N (own x/6)` / `priest summon 1 (own x/2)`

- [ ] **龙息云寿命**：阶段 2/3 的龙息火球落地后，绿色云**约 5 秒消失**（原版是 120 秒）；

- [ ] **龙息不伤自己人**：站在云里只有玩家掉血，**龙蛇自己、幼龙、祭司、龙卫都不掉血**

      范围内没怪 → `0` + 「未命中」；**只有倒计时、按钮数字不出现、也没有任何提示 ⇒ 服务端根本没收到事件**，
      此时去 MCStudio「脚本测试日志」看这三行：`[fycq-slash] server ready`（服务端系统加载了吗）、
      `[fycq-slash] cast from <id>`（事件到了吗）、`[fycq-slash] reject: ...`（被什么挡了：手持物不是剑 / 玩家 id 不在列表）
- [ ] **冷却显示**：释放后按钮中央显示剩余秒数（12 → 1），期间再点无效；服务端也挡（提示「龙息斩冷却中」并把按钮倒计时同步成服务端剩余秒）

- [ ] 日志窗口注意：MCStudio「脚本测试日志」是编辑器另开的 TCP 通道，**窗口没输出 ≠ 脚本没跑**（本次日志里 04:23:56 该通道被远端强制断开过）；重启 MCStudio 再看 `[fycq-skill]` / `[fycq-slash]` 的行

## 7. 已知未完成 / 已知限制（本轮不作为失败项）

- 屏幕 BOSS 血条 UI：**作者明确不做**，只用原版顶部 BOSS 条
- 首杀成就只在**玩家造成最后一击或 60 秒内打中过它**时记；纯环境击杀不计
- 龙息云清理依赖引擎抛出 `minecraft:area_effect_cloud` 的创建事件；若实机云仍超过 10 秒不消失，把 `[fycq-breath]` 日志发我
- 龙息斩**不能靠 `ServerItemTryUseEvent`**（对 `netease:weapon` 实测不触发），已改为 HUD 按钮 + `RightClickBeforeClientEvent`；两者都只上报，结算在服务端
- 触屏拖动依赖按钮的 Move 回调（只在触屏模式触发）；PC 鼠标若拖不动，用 JSON `draggable` 或后续加设置项
- 觉醒四件防御合计 24，超过原版 20 点上限的部分不再增加减伤（只叠韧性/耐久）
- 铁砧不能拿龙鳞修装备（工具被 `level=3` 锁成钻石，盔甲无修复字段）；龙鳞修复走龙巢交互
- 创造模式只能做到"盯着不追"（JSON 无 `is_creative` 过滤器），做不到"连看都不看"
- 三只小怪只在高山/台地/台地类群系的**夜晚**自然刷（亮度 0–7），其它地形不刷；权重 6/3/1 可在 `spawn_rules/` 调
- 幼龙用鹦鹉式 fly 导航（`navigation.fly` + `movement.fly` + `random_fly` + 无重力）；蜜蜂那套 hover 实测只会原地悬停打转，已弃用。若实机仍卡半空/穿墙，把位置截图发我
- 受击红闪依赖 `is_hurt_color`，若引擎不支持则不会闪（不影响其它）
- 附魔台里三个附魔名显示成怪字**不是 bug**：原版用标准银河字母（SGA）符文渲染附魔名，中文环境下就是这种效果
- `mc_preview` 读不了龙蛇的老格式模型（`geometry.drasnea` 根键式），BOSS 模型只能实机看
