怎么拿到它们

全部走工作台合成，材料只用龙裔掉落 + 原版物资。

龙牙 ×2 + 木棍 → 龙牙剑

龙鳞 ×8 → 龙鳞胸甲

龙牙剑 + 龙魂 + 龙鳞 ×4 → 觉醒

龙鳞 ×2 + 木棍 ×2 → 龙巢

龙鳞 ×9 → 龙鳞块（可拆回）

龙晶块 + 金锭 ×4 → 龙晶灯

玩法

四件装备穿齐、拿着龙牙剑、找到龙巢，各有一件事可做。

龙息斩

手持龙牙剑时屏幕会出现一个可拖动的技能按钮，点一下向前方喷出一道龙息；手机版触屏、平板都能用，鼠标右键同样可以。12 秒一次。

龙鳞套装

四件穿齐（原版与觉醒混搭也算）：不怕火 + 持续回血，状态栏只亮一次不闪屏。

龙巢召唤

把龙鳞拿在主手、右键龙巢，第一次只需 8 龙鳞就能唤出龙蛇；之后再召唤需要 1 龙心 + 4 龙鳞。附近已有龙蛇、头顶没空间都会拒绝且不扣材料。

龙巢修复

拿着磨损的龙裔装备右键龙巢，1 个龙鳞修回四分之一耐久，附魔全部保留；也可以用「装备 + 2 龙鳞」重铸成全新的一件。

关于铁砧：龙裔工具在铁砧上只认钻石，盔甲铁砧修不了——这是原版规则，所以本模组给了上面的龙巢修复与重铸两条路。
